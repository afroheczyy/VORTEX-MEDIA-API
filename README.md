# VORTEX MEDIA API

A lightweight media API for VORTEX XMD.

## Features

- YouTube search
- YouTube MP3 downloading
- YouTube video downloading
- 360p / 480p / 720p video quality
- Search-to-download
- yt-dlp powered downloading
- Deno JavaScript runtime
- FFmpeg media processing
- API key support
- Rate limiting
- Concurrent download protection
- Panel/VPS deployment ready

## Requirements

- Node.js 20+
- FFmpeg
- Deno
- yt-dlp
